# Gruzli Official

Официальный маркетинговый сайт платформы Gruzli.

## Назначение

Сайт знакомит с платформой и направляет пользователя в действующее приложение. Он не заменяет приложение, регистрацию, личные кабинеты или backend.

## Три аудитории

- Клиенты — создают запрос на грузовые работы и рассматривают предложения диспетчеров.
- Диспетчеры — публикуют заявки, обрабатывают отклики и координируют исполнителей.
- Грузчики — просматривают ленту заказов, сравнивают условия, откликаются и ведут свои заказы.

## Разработка

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Сайт использует реальные экранные изображения из исходного приложения `borzenkoofficial-lab/gruzli-b99e57fd`. Переходы «Открыть Gruzli» ведут в действующую production-точку приложения: https://gruzli-b99e57fd.vercel.app/

Ссылки на App Store и Google Play не добавлены: подтверждённых публикаций в магазинах в исходном проекте не найдено.
